# Экипаж Кинорулетки

Визуальную правку не делай сам с нуля. Сначала специалист, потом вёрстка, потом проверка. Роли лежат в `.cursor/agents/`.

Промпт каждой роли собран так: кто это (работа, не комплимент), какие языки читает и на каком отвечает, что можно трогать, жёсткие запреты с причиной, форма ответа. Задачу в вызов дописывай отдельно: что сделать сейчас и где смотреть. Не проси роль саму себя переопределять.

## Кого звать

| Жалоба | Кто | Пишет файлы |
| --- | --- | --- |
| Как выглядит экран, скриншот, «кринж» | `kino-designer` | нет |
| Крутилка, виньетка, прожектор, скобки, зерно, `js/fx.js` | `kino-designer` (раздел движения обязателен) | нет |
| Уже есть список правок | `kino-screen` | только CSS, разметка, query `?v=` |
| После правки | `kino-look` | нет |
| Плеер, серый экран, озвучка, чужой iframe | `kino-player` | нет |
| Синхронизация комнаты, Вместе ТВ и другие комнаты | `kino-rooms` | нет |
| Источник фильма не работает, убрать резолвер | `kino-sources` | нет |

Дизайнера и проверку запускай с `readonly`. Им передавай путь к скриншоту, если он есть. Не проси их коммитить.

## Порядок

1. Дизайнер возвращает контракт ниже. Если пунктов нет, ничего не верстай.
2. Слей правки. При споре побеждает читаемость постера: эффект, который режет кадр, выкидывается.
3. Отдай `kino-screen` только этот список. Своих прикрас не добавляй.
4. `kino-look` сверяет diff со списком. Расхождение чинится, а не объясняется.
5. Коммит делает родитель, одним сообщением, после проверки.

## Контракт дизайнера

```
## Вердикт
- ...
## Правки
- файл: селектор или функция
  было: ...
  стало: полное объявление или формула
  зачем: одна фраза
## Не трогать
- ...
```

## Контракт вёрстки

```
## Изменил
- путь: что поменялось
## Кэш
- index.html и 404.html: старый ?v= → новый
## Не трогал
- ...
```

## Контракт проверки

```
## Совпадает
- ...
## Расходится
- пункт спеки → что в diff на самом деле
## Дыры
- пустое, сломанное, обрезанное
```

Карта экранов и запреты: `references/surface.md`. Читай её перед делегированием, не пересказывай агенту наугад.
