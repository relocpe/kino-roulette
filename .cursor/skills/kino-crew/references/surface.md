# Поверхность Кинорулетки

Тёмное приложение. Язык интерфейса русский. Шрифт Golos. Случайный фильм, каталог, карточка, комната «смотреть вместе».

## Цвета

Уже заданы в `css/app.css` на `:root`. Новых не вводить.

- фон `--bg` `#0C0B0A`, поверхности `--surface` `#151311`, `--surface-2` `#1D1A17`
- текст `--ink` `#F1EBE2`, вторичный `--ink-2` `#C4BDB3`, тихий `--ink-3` `#9A948B`
- линия `--line` `rgba(241,235,226,.08)`
- единственный акцент `--amber` `#E8B04A`: кнопка «Крутить», точка навигации, звезда рейтинга
- `--accent` только для жанрового эффекта. На постер и на текст его не лить

Обычный текст на фоне не ниже контраста 4.5:1. Крупный заголовок не ниже 3:1.

## Экраны и селекторы

Рулетка, покой (`index.html`, `css/app.css`):

- лента `.reel` `#reel`, кадры `.strip` `#strip` `.card`
- виньетка `.vig` `#vig`
- рамка измерения `#gate` `.gate` и уголки `.gate i`. Узел `#gate` обязателен: `js/fx.js` `measure()` читает его rect. Уголки можно спрятать, узел нельзя удалять
- перфорация `.reel::before`, `.reel::after`
- пульт `.pult`: «Что» `#fType`, «Жанр» `#fGenre`, «Годы» `#fYears`, «Рейтинг» `#fRate`, кнопка `#spin`

Карточка фильма: `.result`, `.poster`, `.info`, `.facts`, `.actions`, кнопки `[data-act]`.

Каталог (`css/views.css`): `.search`, `.mood`, `.tile`, `.grid`, `.crow`.

Комната: `.wroom`, `.wroom-stage`, `.wroom-frame`, `.wp-sync`, `.wp-remote`, `.wroom-side`, `.wp-users`, `.wp-msg`.

Кэш статики: один и тот же `?v=` в `index.html` и `404.html`. CSS сейчас подключён как `css/app.css` и `css/views.css`.

## Эффект, который уже портил кадр

Жанр «ужасы» в `js/fxpresets.js`: `vig: .55`, `spin.vig: .70`, `vigR: .75`. Шейдер L2 в `js/fx.js`:

```
float v = smoothstep(uVigR - 0.45, uVigR, length(q)) * uVig * (1.0 - inP);
```

`q` растянут по aspect широкой ленты, blend mode overlay. Получается овальная тень по соседним постерам. Плюс CSS `.vig` с `radial-gradient(ellipse 64% 72%...)` и `--vig` до `0.38`. Белые уголки `.gate i` и точки перфорации усиливают вид шаблона.

Перед новой формулой перечитай эти строки. Номера съезжают.

## Запрещено на покое рулетки

- Овал или прожектор, который заходит на соседний постер
- Белые кадровые скобки
- Перфорация киноплёнки как декор
- Размытие соседей
- Жанровый цвет, зерно и вспышка поверх картинки постера
- Новый шрифт, новая библиотека компонентов, английские подписи, lorem

## Можно

- Лента едет. Центральный постер чуть крупнее или светлее соседей, без дыры
- Пульт и янтарная «Крутить» остаются
- Жанр слегка меняет фон вокруг ленты, не сам постер
- На стопе один короткий сдвиг. Без тряски, без луча, без затемнения соседей в ноль
